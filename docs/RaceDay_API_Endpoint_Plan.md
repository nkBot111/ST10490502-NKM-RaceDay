# RaceDay API Endpoint Plan

This document defines the RESTful API endpoints that will be implemented for the RaceDay system in Part 2 of the Portfolio of Evidence. The endpoint plan is based on the RaceDay database design completed in Part 1 and provides the functionality required for authentication, user profiles, events, categories, event enrolments and race results.

The API supports two system roles:

- **Organiser** – creates, updates and deletes events, manages event categories, views event enrolments and captures participant results.
- **Participant** – registers an account, manages their profile, browses available events, enters events, views their enrolments and tracks their personal results.

Role-based access will be enforced at API level. Protected endpoints will require an authenticated user and Organiser or Participant permissions will be applied where necessary.

| HTTP Method | Route | Description | Role Required | Request Body | Expected Response |
|---|---|---|---|---|---|
| POST | `/api/auth/register` | Creates a new RaceDay user account as either an Organiser or Participant. | None | `{ "firstName": "string", "lastName": "string", "email": "string", "password": "string", "role": "Organiser or Participant" }` | **201 Created** – account created successfully. **400 Bad Request** – invalid or missing information. **409 Conflict** – email address is already registered. |
| POST | `/api/auth/login` | Authenticates a registered RaceDay user and returns the information required to access protected endpoints. | None | `{ "email": "string", "password": "string" }` | **200 OK** – authentication successful. **400 Bad Request** – invalid request information. **401 Unauthorized** – email or password is incorrect. |
| GET | `/api/profile` | Retrieves the profile information of the currently logged-in user. | Any authenticated user | None | **200 OK** – profile returned successfully. **401 Unauthorized** – user is not authenticated. **404 Not Found** – profile does not exist. |
| PUT | `/api/profile` | Creates or updates the profile information of the currently logged-in user. | Any authenticated user | `{ "phoneNumber": "string", "dateOfBirth": "YYYY-MM-DD", "emergencyContactName": "string", "emergencyContactNumber": "string" }` | **200 OK** – existing profile updated successfully. **201 Created** – new profile created successfully. **400 Bad Request** – invalid profile information. **401 Unauthorized** – user is not authenticated. |
| GET | `/api/events` | Retrieves all available RaceDay events so that users can browse upcoming events. | Any authenticated user | None | **200 OK** – list of events returned successfully. **401 Unauthorized** – user is not authenticated. |
| GET | `/api/events/{id}` | Retrieves detailed information about a specific event using its EventID. | Any authenticated user | None | **200 OK** – event returned successfully. **401 Unauthorized** – user is not authenticated. **404 Not Found** – event does not exist. |
| POST | `/api/events` | Creates a new RaceDay event. The authenticated Organiser becomes the owner of the event. | Organiser | `{ "categoryId": 1, "eventName": "string", "description": "string", "eventDate": "YYYY-MM-DD", "startTime": "HH:mm", "location": "string", "distanceKm": 10.0, "maximumParticipants": 100, "status": "Open" }` | **201 Created** – event created successfully. **400 Bad Request** – invalid or missing event information. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – user is not an Organiser. **404 Not Found** – selected category does not exist. |
| PUT | `/api/events/{id}` | Updates an existing event owned by the authenticated Organiser. | Organiser | `{ "categoryId": 1, "eventName": "string", "description": "string", "eventDate": "YYYY-MM-DD", "startTime": "HH:mm", "location": "string", "distanceKm": 10.0, "maximumParticipants": 100, "status": "Open" }` | **200 OK** – event updated successfully. **400 Bad Request** – invalid event information. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – user is not an Organiser or does not own the event. **404 Not Found** – event or selected category does not exist. |
| DELETE | `/api/events/{id}` | Deletes an existing event owned by the authenticated Organiser. | Organiser | None | **204 No Content** – event deleted successfully. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – user is not an Organiser or does not own the event. **404 Not Found** – event does not exist. |
| GET | `/api/categories` | Retrieves all available RaceDay event categories. | Any authenticated user | None | **200 OK** – categories returned successfully. **401 Unauthorized** – user is not authenticated. |
| GET | `/api/categories/{id}` | Retrieves information about a specific event category using its CategoryID. | Any authenticated user | None | **200 OK** – category returned successfully. **401 Unauthorized** – user is not authenticated. **404 Not Found** – category does not exist. |
| POST | `/api/categories` | Creates a new event category that can be assigned to RaceDay events. | Organiser | `{ "categoryName": "string", "description": "string" }` | **201 Created** – category created successfully. **400 Bad Request** – invalid or missing category information. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – user is not an Organiser. **409 Conflict** – category name already exists. |
| PUT | `/api/categories/{id}` | Updates an existing RaceDay event category. | Organiser | `{ "categoryName": "string", "description": "string" }` | **200 OK** – category updated successfully. **400 Bad Request** – invalid category information. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – user is not an Organiser. **404 Not Found** – category does not exist. **409 Conflict** – category name already exists. |
| DELETE | `/api/categories/{id}` | Deletes an event category when it is not currently assigned to an event. | Organiser | None | **204 No Content** – category deleted successfully. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – user is not an Organiser. **404 Not Found** – category does not exist. **409 Conflict** – category is currently assigned to one or more events. |
| POST | `/api/events/{eventId}/enrollments` | Enrols the authenticated Participant in a selected RaceDay event. | Participant | None | **201 Created** – enrolment created successfully. **400 Bad Request** – event is closed or cannot accept the enrolment. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – user is not a Participant. **404 Not Found** – event does not exist. **409 Conflict** – participant is already enrolled or the event has reached its participant limit. |
| GET | `/api/enrollments/me` | Retrieves all event enrolments belonging to the authenticated Participant. | Participant | None | **200 OK** – participant enrolments returned successfully. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – user is not a Participant. |
| GET | `/api/events/{eventId}/enrollments` | Retrieves all participants enrolled in a specific event for management by its Organiser. | Organiser | None | **200 OK** – event enrolments returned successfully. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – user is not an Organiser or does not manage the event. **404 Not Found** – event does not exist. |
| DELETE | `/api/enrollments/{id}` | Cancels an event enrolment belonging to the authenticated Participant. | Participant | None | **204 No Content** – enrolment cancelled successfully. **400 Bad Request** – enrolment can no longer be cancelled. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – enrolment does not belong to the authenticated Participant. **404 Not Found** – enrolment does not exist. |
| POST | `/api/enrollments/{enrollmentId}/result` | Captures a race result for a completed participant enrolment. | Organiser | `{ "finishTime": "HH:mm:ss", "overallPosition": 1, "categoryPosition": 1 }` | **201 Created** – result captured successfully. **400 Bad Request** – invalid result information or enrolment is not eligible for a result. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – user is not an Organiser or does not manage the related event. **404 Not Found** – enrolment does not exist. **409 Conflict** – a result already exists for the enrolment. |
| PUT | `/api/results/{id}` | Updates an existing participant race result. | Organiser | `{ "finishTime": "HH:mm:ss", "overallPosition": 1, "categoryPosition": 1 }` | **200 OK** – result updated successfully. **400 Bad Request** – invalid result information. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – user is not an Organiser or does not manage the related event. **404 Not Found** – result does not exist. |
| GET | `/api/events/{eventId}/results` | Retrieves all recorded results for a specific RaceDay event. | Any authenticated user | None | **200 OK** – event results returned successfully. **401 Unauthorized** – user is not authenticated. **404 Not Found** – event does not exist. |
| GET | `/api/results/me` | Retrieves the personal race results and performance history of the authenticated Participant. | Participant | None | **200 OK** – personal results returned successfully. **401 Unauthorized** – user is not authenticated. **403 Forbidden** – user is not a Participant. |

## Endpoint Plan Summary

The endpoint plan provides the minimum functionality required for the RaceDay system while maintaining clear role separation between Organisers and Participants. Authentication endpoints support registration and login while protected endpoints require authentication before access is granted.

Organisers are responsible for event management, category management, viewing event enrolments and capturing race results. Participants can maintain their profiles, browse events, enter events, manage their own enrolments and view their personal performance history.

The endpoint structure will be followed closely when the RESTful API is implemented in Part 2. Any necessary changes identified during implementation will be documented and explained.
